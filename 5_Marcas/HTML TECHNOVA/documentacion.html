Documentación Técnica XML/XSD

Sistema completo de gestión de información mediante XML y validación con esquemas XSD. Proyecto desarrollado para el módulo de Lenguajes de Marcas y Sistemas de Gestión de Información.

Sobre el Proyecto

Este proyecto implementa dos sistemas XML/XSD completos para TechNova Solutions: un sistema de gestión de inventario IT y un catálogo de servicios profesionales. Ambos sistemas incluyen validación exhaustiva mediante esquemas XSD con patrones regex, enumeraciones y restricciones de datos.
